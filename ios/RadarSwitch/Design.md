# RadarSwitch iOS 设计文档（操作与解析）

## 界面与流程

### 蓝牙扫描
- 过滤规则：设备名称以 CNDingtek 或 DC59 开头（不区分大小写）
- 生命周期：离开扫描页自动停止扫描；返回后需手动点击“开始”
- 状态同步：界面显示与内部扫描状态保持一致

### 我的设备
- 删除设备：从配对列表删除后，若为当前选中设备，立即断开连接并清空详情页
- 显示规则：被删除的设备不会在“设备详情”页显示；需回到扫描页重新扫描与配对

### 设备详情
- 模式：参数 / 日志与监控
- 数据处理开关：仅在“设备详情”页启用数据接收与解析，其它页面关闭以节省资源

### 设置与帮助
- 关于：版本号动态读取；开发者中文“深圳鼎恒泰物联科技有限公司”
- 帮助与教程：提供“软件使用教程”（应用引导）与“硬件安装说明”（内联 PDF），胶囊按钮并排展示

## 指令与操作

### 只读查询（Locked）
- 握手：AA，收到 STOP 或 AT+ERR 后进入查询
- 查询队列（均带 CRLF，不发送 TRITH?）：
  - AT+R1?、AT+R2?、AT+R3?
  - AT+ONTH?
  - AT+HOLD?
  - AT+STIME=100、AT+FTIME=100
- 超时与重试：每条查询超时 200ms；无响应时重试本条，最多 3 次；解析到响应立即取消超时并推进队列

### 保存（Save）
- 握手：AA，收到 STOP 或 AT+ERR 后设置
- 设置队列（不发送 TRITH=xx；SlowTime 固定为 10）：
  - AT+R1=<cm>、AT+R2=<cm>、AT+R3=<cm>
  - AT+ONTH=<灵敏度>
  - AT+STIME=10、AT+HOLD=<延迟秒×10>、AT+FTIME=100
- UI 同步：收到 AT+OK 后，用已发送值直接更新界面（R1/R2/R3、ONTH、HOLD、STIME/FTIME）

### 恢复出厂（Restore）
- 入口：AT+INIT → AT+OK
- 默认设置（不设置 TRITH）：
  - AT+R1=200、AT+R2=500、AT+R3=1000
  - AT+ONTH=4
  - AT+STIME=10、AT+FTIME=100、AT+HOLD=200

## 数据解析逻辑

### 查询响应 AT+XXXX=YYYY
- 距离：AT+R1=/R2=/R3= 返回厘米，界面显示米（/100）
- 灵敏度：AT+ONTH= 直接赋值
- 延迟时间（原离开延迟）：AT+HOLD=，秒数 = 值 / 10
- 响应到达：取消当前命令超时、清除重试计数、立即发送下一条
- 正则：允许等号两侧空格与数字后附加字符；不限定行首

### 监控数据与状态
- 状态：行含 ON → “状态：开启”；含 OFF → “状态：关闭”
- 目标行：格式 `code, distcm[, ...]`
  - 中文：code=1 → “检测到运动，距离Xcm”；code=2 → “检测到微动，距离Xcm”
  - 英文：code=1 → “motion detected Xcm”；code=2 → “presence detected Xcm”
  - 特例：当行仅为 `0` 或 `dist == 0` 时，统一显示“无目标 / no object”

### 窗口串解析（GPIO）
- 仅在“只读查询”流程中启用
- 支持 Range1/2/3 值的拼接解析与边界提交（MR1TH）
- 启用时会将当前显示参数清零为基线，随后按窗口串逐步更新

## 资源与内存优化

- 数据处理开关：仅在设备详情页启用数据接收与解析，其它页面关闭
- 扫描生命周期：离开扫描页立即停止扫描；返回后手动开启
- 日志渲染：使用索引作为 ForEach ID，避免相同文本引发渲染警告
