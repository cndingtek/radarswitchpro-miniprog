# Screenshots Placement Guide

Place the following PNG files in this directory to enable images in the root README:

- `scan.png`
- `params-readonly.png`
- `params-edit.png`
- `restore-defaults.png`
- `logs.png`
- `settings.png`

Recommendations:
- Format: PNG
- Portrait width: ~1080 px (or device native resolution)
- Naming: lowercase with hyphens to keep stable links

中文提示：请将以上文件名的截图（PNG）置于此目录 `docs/screenshots/`，以使 `README.md` 中的图片正常显示。
