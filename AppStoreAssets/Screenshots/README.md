## 📸 操作步骤
1. 打开项目 `ios/RadarSwitch.xcodeproj`。
2. 在顶部选择模拟器 (例如 "iPhone 15 Pro Max")。
3. 点击 `Run` (Cmd + R) 启动 App。
4. 导航到要截图的界面。
5. 按键盘 **`Cmd + S`** (截图会自动保存在您的**桌面**)。
6. 将截图拖入本目录下的对应文件夹 (需手动整理)。
